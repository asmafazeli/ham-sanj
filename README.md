# هم‌سنج (HamSanj) — محصول Vibe Coding برای مصاحبه QC AI

ابزار کوچک کنترل کیفیت برای سنجش **همدلی** و **لحن متأثر از سوگیری‌های شناختی** در چت پشتیبانی.

## اجرا

```bash
cd ham-sanj
npm install
npm run dev
```

سپس آدرس محلی Vite را در مرورگر باز کن (معمولاً `http://localhost:5173`).

## برای ارائه مصاحبه

1. تعریف vibe coding: ساخت محصول با کمک AI coding tools (اینجا: Cursor)
2. دمو: نمونه ضعیف / تند / سوگیری‌دار → Score پایین + بایاس‌های تشخیص‌داده‌شده؛ نمونه خوب → Score بالا
3. نشان دادن JSON خروجی `{ Score, Reason, Tone, Biases }`
4. اتصال به زنجیره: همین JSON ورودی n8n و پرامپت LLM است

## استاندارد سوگیری‌ها (صادقانه)

**هیچ شمارش رسمی ایزو برای «تعداد کل بایاس‌های شناختی» وجود ندارد.**

منابع رایج:

- مبانی Kahneman & Tversky و کتاب *Thinking, Fast and Slow*
- Cognitive Bias Codex / فهرست‌های ویکی‌پدیا معمولاً حدود **۱۸۰–۲۰۰** بایاس نام‌گذاری‌شده را فهرست می‌کنند

برای QC لحن پشتیبانی، فهرست کامل دایره‌المعارفی مفید نیست. هم‌سنج یک **زیرمجموعه عملی ۱۰تایی** را پوشش می‌دهد که مستقیماً روی لحن، همدلی و سرزنش در چت اثر می‌گذارند (تأیید، اسناد بنیادی، لنگر، منفی‌نگری، شکاف همدلی، در دسترس‌بودن، واکنش دفاعی، قاب‌بندی، توهم شفافیت، اقدام فوری).

دکمه «درباره استاندارد» در UI همین توضیح را نشان می‌دهد.

## نکته فنی صادقانه

موتور فعلی یک **rubric دمو آفلاین** است تا بدون API و اینترنت هم دمو پایدار باشد.
در نسخه واقعی، همان پرامپت QC به مدل LLM وصل می‌شود.
